Echo-Scale

Complete Guide & Instructions

Section 1: What is Echo-Scale
1

What is Echo-Scale?

echo-scale is a Microtonal Scale system for any synth/MIDI setup. It provides precise microtonal control with Root/Transpose, Note Finder, and complete MIDI Mapping for advanced scale manipulation.

Section 2: Quick Start
2

Quick Start

  1. Open Scale and activate microtonal mode.
  2. Choose Root (C…B) and select your desired scale preset.
  3. If needed, set Transpose (e.g. +2 semitones). Everything adjusts correctly.
  4. Select Mono/Poly according to your instrument/host.
  5. Play. Tap on the piano to quickly mark/unmark scale notes.
Section 3: Interface
3

Interface

Scale (Microtonal) On/Off: Enables microtonal rendering of scale notes with precise pitch control.

Root & Transpose: Root: C–B. Transpose: in semitones. Everything you hear is transferred correctly across the scale.

Piano Keys: Tap to mark/unmark scale notes. Visual feedback shows which notes have microtonal offsets applied.

Scale Presets: Choose from various microtonal scales or create your own custom scale.

Section 4: Microtonal Scale Function
4

Microtonal Scale Function

Scale (Microtonal): Applies microtonal tuning to selected scale notes. Default Pitch Bend Range: –60 (tap the value to change). When entering a note, a picker appears where you can set manual offset per note for precise microtonal control.

Precision Control: Each note can have its own microtonal offset, allowing for complex scale systems and experimental tunings.

Section 5: Mono/Poly Modes
5

Mono / Poly Modes

Scale in Mono: Works everywhere without special setup. Microtonal pitch bends are applied per note.

Scale in Poly: Often requires "mirroring" sound/path to apply correctly (depends on synth/host). For best results, use MPE-capable instruments.

MPE / Pitch Bend: Microtonal works with Pitch Bend. For polyphonic microtonal, check if your instrument supports MPE or special formats. For synths with SysEx microtuning, Echopais provides separate tools that speak native SysEx (more accurate, less setup).

Section 6: Note Finder
6

Note Finder

  • Map a button from your instrument to Note Finder.
  • Press the button and then play the notes you want: the app marks microtonal offsets on the selected notes.
  • Press again without selection to clear all marked notes.
  • Use this feature to quickly build custom scales by ear or to match specific tuning systems.
Section 7: MIDI Mapping
7

MIDI Mapping & Map Manager

Mapping/Learn: Learn any hardware button/slider to app functions for hands-on control.

Map Manager (press & hold): View/change mapped controls and activation pole (Momentary or Toggle).

Global "MIDI Switch Toggle": Changes overall activation type for trigger buttons (Momentary/Toggle).

Panic: Immediate all-notes-off if a note "sticks" or hangs.

Section 8: Auto Recognition
8

Auto Mono/Poly & Sound Recognition

Two automation methods for seamless workflow:

  1. Portamento CC Auto: Recognizes mono/poly from Portamento CC. Fast and convenient, ~80% reliability.
  2. Auto Sound Recognition (Learn): You learn the sound as Mono or Poly once. Then, when you select the same sound, the app automatically returns to the correct mode. More reliable for live performance.
Section 9: Settings
9

Settings

  • MIDI In/Out & Channel Routing: Port selection and channel routing configuration.
  • Note Range: Define the range/octaves where Scale is applied.
  • MIDI Learn Options: Settings for toggle buttons and auto modes (Portamento Auto & Sound Recognition).
  • PC/MPE Mode: For hosts/instruments that support MPE, enable MPE in the plugin/instrument for correct polyphonic microtonal.
  • Scale Custom: In Custom mode you create your own scale—you define for each note which microtonal offset to apply.
  • Pitch Bend Range (Microtonal): Default –60. Touch it and enter the value you want to match your synth\'s pitch bend range.
  • Synth Tips: Check your synth\'s MIDI settings and pitch bend range to ensure proper microtonal operation.
Section 10: Presets
10

Presets

Save and load your custom Scale presets. Store your favorite microtonal scales and recall them instantly. Presets include all note offsets, root settings, and transpose values for complete recall of your tuning systems.

Section 11: Best Practices
11

Best Practices

  • For Microtonal Mono: works immediately on any synth without special setup.
  • For Microtonal Poly: prefer MPE-capable instruments/hosts.
  • Keep consistent Pitch Bend Range between app and synth.
  • Use Sound Recognition for reliable auto Mono/Poly switching in live performance.
  • Save presets for different musical contexts—Arabic maqams, Indian ragas, experimental tunings.
